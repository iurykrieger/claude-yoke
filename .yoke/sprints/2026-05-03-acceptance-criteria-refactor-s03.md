## Sprint objective

Rewrite `skills/acceptance-criteria/SKILL.md` end-to-end. The new
skill body documents a Senior QA persona that runs pre-flight (config,
active task, PRD approved, Tech Spec approved), emits a structured
≤ 25-line resume of PRD + Tech Spec, drives a 1–5 round
lettered-options grill scoped to five quality-gate buckets (US
enumeration, DoD per US, AC per US, sensor pool, cross-cutting FRs)
while challenging at least one vague answer per round, materializes
the artifact at `.yoke/acceptance-criteria/<slug>.md` with the Trigger
3 binding metadata header, validates the sensor pool via the helper
shipped in Sprint 2, and renders the shared approval menu with
`next_skill = /yoke:implement`. A Quick-Round fast-track collapses the
dialogue to one confirmation when PRD goals + Tech Spec sprints already
imply unambiguous shape (mitigation for grill fatigue per the PRD's
risk register).
