## Sprint objective

Triage and migrate the existing 45 sensor files in a single atomic commit — one-shots from doctrine-canonization deleted, generic harness-level sensors rewritten in the new schema with conservative cost defaults. Implement four test scripts (one one-shot migration test, three permanent tests for dispatch-by-type, body-lint and consolidation-stage). Wire the three permanent tests as a CI gate via the appropriate behavior-named smoke under `tests/smoke/`. End state: branch is internally consistent, every contract reference resolves against the new catalog, runtime + catalog + tests are aligned. This is the merge point for the entire PRD.
