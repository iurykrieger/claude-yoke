## Sprint objective

Reshape `templates/acceptance-criteria.md` to the new hierarchy with
stable, parseable anchors: header → binding statement → `## User
Stories` → per-story (`### US-### — <title>` + `#### Definition of
Done` + `#### Acceptance Criteria`) → `## Functional Requirements` →
`## Sensor pool` → `## Open Questions`. Strip the `## User Stories`
block from `templates/prd.md` and the corresponding US-### enumeration
instructions from `skills/discover/SKILL.md`. Add
`lib/sensors/resolve-pool.sh` as the deterministic helper Sprint 3 will
call before rendering Trigger 3 — it parses the artifact's `## Sensor
pool` block and exits non-zero if any listed ID fails to resolve to a
`.yoke/sensors/<id>.md` file. After this sprint the artifact's static
shape is in place; Sprint 3 wires the interactive skill that fills it.

### Task 2026-05-03-acceptance-criteria-refactor-s02-t04

**Story:** Add `lib/sensors/resolve-pool.sh` so the Phase 3 skill (Sprint 3) has a deterministic gate: any acceptance-criteria document whose `## Sensor pool` references an unresolvable sensor ID is rejected before ratification.

**Technical implementation:** Create `lib/sensors/resolve-pool.sh` (`#!/usr/bin/env bash`, bash 4+). Export a function `resolve_sensor_pool <artifact-path>` that: (a) `mapfile`-extracts the `## Sensor pool` block from the artifact; (b) parses one sensor ID per `^- ` bullet line; (c) for each ID, asserts `test -f .yoke/sensors/<id>.md`; (d) on any failure, prints `wm: sensor pool unresolved: <id>` to stderr and exits non-zero with the count of unresolved IDs; (e) on success, prints the resolved count to stdout and exits 0. Empty pool exits 0 with count 0 (the calling skill enforces non-empty per the artifact contract). Reuse the section-extract pattern from `lib/working-memory/scaffold-sprints.sh` for consistency.

**Validation:** Add `tests/unit/sensor-pool-resolve.test.sh` constructing three fixture artifacts under `tests/unit/fixtures/sensor-pool/`: (a) all-valid pool of 3 IDs from `.yoke/sensors/`; (b) one-unknown pool with `bogus-sensor` listed; (c) empty pool. Invoke `resolve_sensor_pool` against each, assert exit codes 0 / non-zero / 0 and stderr contents.

**Acceptance criterion:** `bash tests/unit/sensor-pool-resolve.test.sh` exits 0.
