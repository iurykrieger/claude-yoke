## Overall objective

Harden `lib/canonical-memory/resolve-provider.sh` so that sourcing it
through `bash -c "set -u; source ..."` from outside the plugin root
never trips `BASH_SOURCE[0]: parameter not set`. The slow-path that
derives the plugin root must be `set -u`-safe; the existing
`YOKE_PLUGIN_DIR` fast-path stays unchanged; a clear `wm: `-prefixed
diagnostic fires only when both paths are unavailable. A regression
smoke test reproduces the failing transcript dispatch and is wired
into CI so the bug stays fixed.

## Sprints

### Sprint 01 — set -u-safe plugin-root resolution

**Delivery objective:** Ship a fixed `lib/canonical-memory/resolve-provider.sh`
whose `_yoke_provider_plugin_dir` helper survives `bash -c "set -u; source ..."`
from any working directory, plus a regression smoke test wired into
`.github/workflows/tests.yml` that reproduces the original failure on
pre-fix code and passes on post-fix code. Existing happy-path callers
(direct `source` from the plugin root) continue to work byte-for-byte;
the four documented exit codes (0/3/4/5) keep their semantics.

**Tasks:** see `.yoke/sprints/2026-05-03-resolve-provider-set-u-safety-s01.md` `## Tasks` section.

## Contracts and interfaces

- **`_yoke_provider_plugin_dir` (internal helper)** — bash function in
  `lib/canonical-memory/resolve-provider.sh`. Inputs: none (reads env
  vars `YOKE_PLUGIN_DIR` and array `BASH_SOURCE`). Output: prints the
  absolute plugin root on stdout, returns 0. On unrecoverable failure
  (both inputs empty), prints a `wm: `-prefixed diagnostic to stderr
  and returns non-zero; the caller `_yoke_providers_yaml_path` and
  `yoke_resolve_provider` propagate the failure as exit code 5 with
  the existing stderr surface preserved.
- **`yoke_resolve_provider` exit codes** — unchanged: `0` (resolved),
  `3` (`.yoke/config.yaml` missing), `4` (`canonical_memory.provider`
  missing), `5` (provider not in `providers.yaml`). The new
  "no plugin root resolvable" failure mode also surfaces as `5`,
  consistent with the existing convention that wraps "providers.yaml
  unreadable" failures as `5`.
- **`tests/smoke/resolve-provider-set-u-safety.test.sh` (new)** —
  bash script. Inputs: none. Behavior: spawns a subshell via
  `bash -c "set -u; source <plugin>/lib/canonical-memory/resolve-provider.sh; yoke_resolve_provider"`
  from a temp directory containing a fixture `.yoke/config.yaml` whose
  `canonical_memory.provider` is one of the entries in the plugin's
  `providers.yaml`. Exits 0 when the helper resolves successfully and
  no `BASH_SOURCE[0]: parameter not set` text appears on stderr; exits
  non-zero otherwise. Uses the `tests/` watchdog convention
  (`sleep 600 && kill -TERM $$ &`) per `concepts/yoke-conventions`.
- **CI matrix entry** — one new row in `.github/workflows/tests.yml`
  invoking `tests/smoke/resolve-provider-set-u-safety.test.sh`.
