## Functional requirements

Six binary, observable criteria lifted verbatim from the PRD. Each maps
to at least one sensor.

### Criterion FR-1 — Defensive `${BASH_SOURCE[0]:-}` deref replaces the bare form

`grep -nE '\$\{BASH_SOURCE\[0\]\}' lib/canonical-memory/resolve-provider.sh` returns no matches. Every reference to `${BASH_SOURCE[0]}` in the file uses the safe `${BASH_SOURCE[0]:-}` form (or an equivalent guarded read). The fix is local to `_yoke_provider_plugin_dir`; the file's `set -uo pipefail` declaration at line 46 is unchanged.

### Validation

- **lint** — pass = `shellcheck lib/canonical-memory/resolve-provider.sh` exits 0 with no new warnings; fail = any warning that did not exist before this PRD.
- **tests-smoke** — pass = `bash tests/smoke/resolve-provider-set-u-safety.test.sh` exits 0 (the test sources the helper under `set -u` from outside the plugin root and asserts no `BASH_SOURCE[0]: parameter not set` appears); fail = exit non-zero or the `parameter not set` string appears on stderr.

### Criterion FR-2 — `YOKE_PLUGIN_DIR` fast-path preserved

When `YOKE_PLUGIN_DIR` is exported and points at a valid plugin path, `_yoke_provider_plugin_dir` uses it without consulting `BASH_SOURCE[0]`. Lines 50–53 of the helper (the existing `[ -n "${YOKE_PLUGIN_DIR:-}" ]` guard) remain in place ahead of the slow path; `${YOKE_PLUGIN_DIR:-}` continues to be the first branch.

### Validation

- **tests-smoke** — pass = a sub-test inside `tests/smoke/resolve-provider-set-u-safety.test.sh` exports `YOKE_PLUGIN_DIR=/tmp/fake-plugin` (a sentinel that does not contain `providers.yaml`) and confirms the helper resolves to that path (verifiable via the `providers.yaml missing from plugin root (/tmp/fake-plugin/providers.yaml)` stderr line), proving the fast-path was taken; fail = the helper consults `BASH_SOURCE[0]` instead and resolves to a different path.

### Criterion FR-3 — Actionable error when both fallbacks empty

When `YOKE_PLUGIN_DIR` is unset and `BASH_SOURCE[0]` is unavailable, `yoke_resolve_provider` returns non-zero with exactly one `wm: `-prefixed stderr line that names both `YOKE_PLUGIN_DIR` and `BASH_SOURCE[0]` and directs the user to export `YOKE_PLUGIN_DIR`.

### Validation
