## Functional requirements

Measurable, observable. Each FR maps to a concrete sensor.

- [ ] **FR-1** — The cascade input enumeration walks every `.yoke/contracts/*.md` archive and emits an `occurrences:` count per candidate without breaking the legacy single-`contracts.md` path. Sensor: `cascade-occurrences-test`.
- [ ] **FR-2** — The semantic-overlap layer never invents candidates the deterministic floor did not admit and never coalesces contracts whose `decision:` fields directly contradict. Sensor: `semantic-overlap-rewrite-test`.
- [ ] **FR-3** — Every promoted concept carries the mandatory rippability frontmatter (`ratified`, `model_calibrated_against`, `last_validated`, `traceability`, `impact_level`) per [[yoke-pattern-memory-model]]. Sensor: `promoted-concept-frontmatter-test`.
- [ ] **FR-4** — Every promoted concept's `applies_to:` list resolves to an existing actor entity AND that actor's body carries a backlink to the promoted concept (bidirectional invariant). Sensors: `promoted-concept-backlink-test`, `contract-promotion-bidirectional-self-test`, `contract-promotion-bidirectional-integration`.
- [ ] **FR-5** — Every promoted concept's `tags:` list contains both `kind/contract` and `yoke-framework`. Sensor: `promoted-concept-frontmatter-test`.
- [ ] **FR-6** — Slug collisions in `concepts/` are resolved by the regenerate-and-retry rule with a 5-attempt cap; on exhaustion the helper exits non-zero with a diagnostic. Sensor: `promoted-concept-slug-collision-test`.
- [ ] **FR-7** — On a host project lacking the actor entity at promotion time, the helper creates it under Model C from the canonical actor template before writing the backlink. Sensor: `promoted-concept-actor-create-test`.
- [ ] **FR-8** — Hard-contradiction detection in the cascade routes the impact class to require synchronous human ratification (Trigger 5 surface), never auto-merging. Sensor: `semantic-overlap-rewrite-test` (contradiction subcase).
- [ ] **FR-9** — The bidirectional-link sensor is discoverable by `/yoke:ack-sensors --mode readiness` and is executable from a clean checkout. Sensor: `contract-promotion-bidirectional-readiness`.
- [ ] **FR-10** — No regression in the existing single-`contracts.md` cascade path: the byte-for-byte golden output is preserved except for the additive `occurrences: 1` field. Sensor: `cascade-occurrences-test` (legacy-fixture subcase).
