## Inferential sensors

Per `concepts/yoke-pattern-sensors`, inferential sensors carry full
calibration metadata (model id, calibration date, rubric, JSON verdict
schema) in their per-sensor files under `.yoke/sensors/<id>.md`.
Calibration metadata lands in Sprint 5+ (the v3.0 dogfood follow-up
PRD); v3.0 ships placeholders so the gating contract is decidable.

- **council-arbiter** — gates FR-3 + FR-4. Spawned by `/yoke:implement`
  between réplica rounds with ≥ 1 réplica. JSON verdict schema in the
  Tech Spec's `### Contradiction-detection arbiter` section.
- **personas-irreducible-on-fixture** — gates FR-5. Spawned post-cycle
  on the realistic-task fixture; emits a structured verdict on whether
  each persona's finding lens is distinct from the v2.x equivalent.
- **language-policy-en-us** — gates FR-9. Reads modified files; emits
  pass/fail per the en-US language policy.
- **no-portuguese-content** — same as `language-policy-en-us` from a
  different angle (some BDD scenarios cite the latter, FR-9 cites both
  for clarity).
