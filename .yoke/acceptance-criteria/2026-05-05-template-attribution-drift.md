### US-001 — Correct producer/trigger attribution in `templates/sprint.md`

As a Tech Spec author or implementation agent reading
`templates/sprint.md` to learn the lifecycle of a sprint runtime
bundle, I want the template's opening blockquote and closing trailer
to cite the actual producer skill (`/yoke:generate-sprints`) and the
actual ratifying gate (Trigger 2.5), so that I am not misled into
looking for stage 3 of `/yoke:tech-spec` (which has no stage 3) or
Trigger 2 (which ratifies the Tech Spec, not the sprint plan).

#### Definition of Done

- [ ] `templates/sprint.md` opening blockquote (the first
      blockquote-paragraph after the H1) cites `/yoke:generate-sprints`
      explicitly by name and Phase 2.5 explicitly by phase number.
- [ ] `templates/sprint.md` closing trailer (last blockquote in the
      file) carries identical attribution to the opening blockquote.
- [ ] `templates/sprint.md` legacy-flow carve-out paragraph
      (currently lines 89–90) is preserved verbatim — historical
      statement about pre-cutover sprint files is intentional.
- [ ] `templates/sprint.md`'s 5 H2 sections (`## Sprint objective`,
      `## Sprint DoD`, `## Tasks`, `## Functional acceptance criteria`,
      `## Sensors`) remain present in the documented order.
- [ ] `templates/sprint.md`'s `(Realizes:)` US-trace clause and its
      `legacy-flow` carve-out remain present (preserves

### US-003 — Add structural `template-metadata-fidelity` sensor with self-test

As Sr QA / Sr Staff in a future ralph loop on this codebase, I want
a structural sensor that pins the producer/trigger attribution lines
of every producer-owned template, so that a future producer rename
does not silently leave templates with stale attribution metadata
(the regression that this fix is repairing).

#### Definition of Done

- [ ] `lib/sensors/template-metadata-fidelity.sh` exists, is
      executable (`chmod +x`), and starts with `#!/bin/bash` followed
      by `set -euo pipefail` (matches the
      `lib/sensors/no-vibeflow-refs.sh` discipline).
- [ ] `tests/sensors/template-metadata-fidelity.test.sh` exists, is
      executable, and exercises three subcases: positive (real
      `templates/` tree → exit 0), negative (drifted fixture → exit
      non-zero with the expected violation class on stderr),
      reverse-fixture (synthetic producer-owned template → exit 0).
- [ ] Sensor source ≤ 0.01MB (≤ ~10 KB); self-test source ≤ 0.02MB
      (≤ ~20 KB).
- [ ] `shellcheck` exits 0 on both new files (per repository
      `## Linting` convention).
- [ ] Sensor encodes 5 violation classes: `producer-mismatch`,
      `trigger-mismatch`, `producer-skill-missing`, `template-missing`,
      `legacy-string-leaked`. Each class is exercised by the
      negative subcase.
- [ ] Sensor handles the self-reference paradox per the
      `lib/sensors/no-vibeflow-refs.sh` precedent — the search needles
      and exclusions ensure the sensor's own source and the self-test
      do not trip its own checks.

#### Acceptance Criteria

- **AC-003-1:** `bash lib/sensors/template-metadata-fidelity.sh`
  exits 0 with empty stderr against the post-fix `templates/` tree
  (silent success per the structured-sensor-output convention).
- **AC-003-2:** `bash tests/sensors/template-metadata-fidelity.test.sh`
  exits 0 (all three subcases pass) and prints exactly one
  `PASS:` line per subcase to stdout.
- **AC-003-3:** When the sensor fires the negative subcase against a
  drifted fixture, every emitted violation block on stderr matches
  the structured YAML shape `id: template-metadata-fidelity:<template>:<violation-class>`
  and carries the four required keys (`id`, `location`,
  `correction_instruction`, `reference`), per the
  `[[yoke-pattern-sensors]]` structured-output convention.
- **AC-003-4:** `time bash lib/sensors/template-metadata-fidelity.sh`
  reports wall-clock ≤ 100ms p95 over 5 invocations against the real
  `templates/` tree.
- **AC-003-5:** `shellcheck lib/sensors/template-metadata-fidelity.sh tests/sensors/template-metadata-fidelity.test.sh`
  exits 0 with no warnings.
- **AC-003-6:** `bash lib/sensors/template-metadata-fidelity.sh`
  invoked at the **pre-fix** state (with `templates/sprint.md` still
  carrying the false `/yoke:tech-spec` stage 3 attribution and
  `templates/task.md` still on disk if it were on the allowlist)
  exits non-zero — the sensor catches the regression that this fix
  is repairing.
